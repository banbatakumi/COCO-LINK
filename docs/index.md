# COCO-LINK

**避難所・介護施設で、複数台のロボットが協調するパフォーマンスで人々を楽しませ、心のケアをしながら物資の運搬も担う
実用型パフォーマンスロボットシステム**（立命館大学 理工学部 ロボティクス学科「ロボット創造実験」）
