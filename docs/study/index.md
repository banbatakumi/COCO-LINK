# 学習資料：COCO-LINK を説明できるようになる

この資料は、班員全員が **最終週の口頭試問で、自分たちのシステムの中身と使っている技術を自分の言葉で説明できる** ようになるためのものです。

授業で習った制御工学やプログラミングの内容を **復習しながら** 読めるよう、各ページは
**用語の意味 → 直感（図・たとえ）→ 数式 → このプロジェクトでどう使ったか** の順に構成しています。

## 30 秒で説明する COCO-LINK

まずはこれを **全員が何も見ずに言える** ようにしましょう。

!!! abstract "COCO-LINK とは"
    避難所や介護施設で、**複数台の小型 2 輪ロボットが隊列やフォーメーションで動くパフォーマンス** で人を楽しませ、
    **物資の運搬** も担うロボットシステムです。

    システムは **操作GUI（上位制御）・シミュレータ・ビジョン** の 3 つの PC ソフトと、ESP32 を載せたロボットで構成され、
    すべて **UDP 通信** でつながっています。天井カメラがロボット上の **ArUco マーカー** で位置と向きを測り、
    PC が隊形の目標を計算して各ロボットに速度を指令し、ロボットは **車輪速度の PI 制御** でそれに従います。

    工夫した点は 3 つです。

    1. **シミュレータが実機とまったく同じ通信をする** ので、シミュレータで作った制御がそのまま実機で動く
    2. **システム同定** で、実機を決まった動きをさせてモータや車輪の特性を測り、制御のゲインを理論的に決める
    3. フォーメーションでは **ハンガリアン法** で各ロボットの行き先を最適に割り当て、人追従では **人の通った道をたどる** 隊列を作る

## 口頭試問までの勉強の進め方（おすすめ）

1. **1 周目**: 1〜7 をざっと読む。まずは「ひとことで」と図で全体をつかむ（数式は 2 周目でじっくり）
2. **動かしてみる**: シミュレータと操作GUIを起動し、フォーメーション・人追従・システム同定を実際に動かす（起動方法はリポジトリの README）。
   **自分の目で見た動きは説明しやすい**
3. **2 周目**: 担当分野のページを数式まで読み、「このプロジェクトでは」の節に出てくるコードを GitHub で開いてみる
4. **想定問答集で練習**: 2 人 1 組で、片方が質問、片方が答える。**30 秒以内に答える** 練習をする。詰まった質問のページを読み直す
5. **全員の担当外も最低限**: 自分の担当外でも、想定問答集の「★」が付いた質問には全員が答えられるようにする

!!! tip "口頭試問で大事なこと"
    - **用語を正しく使う**（「同定」「時定数」「フィードフォワード」などを曖昧に使わない）
    - **なぜそうしたか** を言えるようにする。「〜だから〜を選んだ」という形で答えると説得力がある
    - **できていないことは正直に**。ファームウェアは仕様書まで、実機での検証はこれから、という現状を隠さず、
      「シミュレータでどこまで確認したか」「実機ではどう確かめるつもりか」を言えれば十分評価される
