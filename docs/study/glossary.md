| 逆モデル | 「出したい出力」から「必要な入力」を計算するモデル。FF に使う | [2.7](02_control_basics.md#27-フィードフォワードと-2-自由度制御) |
| モデル | 制御対象の性質を表す式 | [2.3](02_control_basics.md#23-モデルと伝達関数) |
| ラプラス変換 | 微分方程式を掛け算の式に変える道具。$d/dt \to s$ | [2.3](02_control_basics.md#23-モデルと伝達関数) |
| 伝達関数 | 出力 ÷ 入力 をラプラス変換で表したもの。要素の性質 | [2.3](02_control_basics.md#23-モデルと伝達関数) |
| 一次遅れ系 | $K/(\tau s+1)$。ステップ入力に指数関数的に近づく | [2.4](02_control_basics.md#24-一次遅れ系ゲイン-k-と時定数-τ) |
| ゲイン $K$ | 定常的な出力 ÷ 入力。一次遅れ系の最終的な大きさ | [2.4](02_control_basics.md#24-一次遅れ系ゲイン-k-と時定数-τ) |

| ステップ応答 | 入力を一気に変えたときの出力の変化 | [2.4](02_control_basics.md#24-一次遅れ系ゲイン-k-と時定数-τ) |
| 立ち上がり時間 | 最終値の 10 % → 90 % の時間 | [2.5](02_control_basics.md#25-ステップ応答の評価指標) |
| オーバーシュート | 目標を行き過ぎた量 | [2.5](02_control_basics.md#25-ステップ応答の評価指標) |
| 定常偏差 | 十分時間がたっても残る誤差 | [2.5](02_control_basics.md#25-ステップ応答の評価指標) |
| PID 制御 | 比例（今）・積分（過去）・微分（未来）で操作量を決める | [2.6](02_control_basics.md#26-pid-制御) |
| PI 制御 | D を除いたもの。COCO-LINK の車輪制御 | [2.6](02_control_basics.md#26-pid-制御) |
| 飽和 | 操作量・出力に上限があること | [2.8](02_control_basics.md#28-非線形性飽和と不感帯) |
| 不感帯 | 入力が小さいと出力が出ない範囲。モータは摩擦で回らない | [2.8](02_control_basics.md#28-非線形性飽和と不感帯) |
| 不感帯補償 | 不感帯の分をあらかじめ足しておくこと | [2.8](02_control_basics.md#28-非線形性飽和と不感帯) |
| 積分ワインドアップ | 飽和中に積分項が溜まり続け、行き過ぎる現象 | [2.9](02_control_basics.md#29-積分ワインドアップとアンチワインドアップ) |
| アンチワインドアップ | 飽和中は積分を止める対策 | [2.9](02_control_basics.md#29-積分ワインドアップとアンチワインドアップ) |
| ローパスフィルタ（LPF） | ゆっくりした変化だけを通し、ノイズを除く。遅れが出る | [2.10](02_control_basics.md#210-ローパスフィルタ) |
| サンプリング周期 | 測って計算して出す間隔。COCO-LINK のロボット内は 10 ms | [2.11](02_control_basics.md#211-サンプリングと離散化) |
| 離散化 | 連続時間の式を、一定間隔ごとの式に直すこと | [2.11](02_control_basics.md#211-サンプリングと離散化) |
| 零次ホールド（ZOH） | 次の計算まで出力を同じ値に保つこと | [2.11](02_control_basics.md#211-サンプリングと離散化) |
| 安定性 | 振動が大きくなっていかないこと。極が左半平面にあれば安定 | [2.12](02_control_basics.md#212-安定性と遅れ) |
| むだ時間 | 入力してから出力に表れるまでの純粋な遅れ。不安定の原因 | [2.12](02_control_basics.md#212-安定性と遅れ) |
| カスケード制御 | 速い内側ループと遅い外側ループの多重構造 | [2.12](02_control_basics.md#212-安定性と遅れ) |
